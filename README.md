# 🕹️ CHIP-8 Emulator

A simple **CHIP-8 emulator/interpreter** written in **C**, using **SDL3** for graphics and input.  
It can load and run CHIP-8 ROMs and emulate the classic 64×32 monochrome display.

---

## ✨ Features

- Executes the full CHIP-8 instruction set  
- 64×32 pixel monochrome display  
- Memory, registers, and stack emulation  
- Keyboard input using SDL3  
- Delay and sound timers (sound optional)  
- Loads external `.ch8` ROM files

---

## ⚙️ Requirements

- C compiler (GCC or Clang)  
- **SDL3** development library
